# Public Assets Structure

Directory structure compliant with specification section 14:
- models/: Validated 3D GLB/glTF models
- textures/: Environment and UI textures
- materials/: Material definition caches
- animations/: Animation clip references
- audio/: Audio assets and fallback sound files
- shaders/: GLSL custom shader files
- ui/: Icons and UI elements
- temp/: Staging folder for unverified assets
