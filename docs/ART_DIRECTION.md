# 3D 釣魚探索遊戲 - 美術風格與基準規範 (Art Direction)

## 1. 核心視覺風格定位
- **靈感融合**：寶可夢街機的鮮明色彩與生動視覺回饋 +《動物森友會》(Animal Crossing) 的柔和溫馨自然氛圍。
- **基調**：明亮、舒適、放鬆、充滿自然奇觀與探索驚喜。

## 2. 色彩範疇 (Color Palette)
- **草地與自然植被**：
  - 春季：柔和嫩綠 (#7BC676, #98D882) 帶櫻粉點綴 (#FFAAA6)。
  - 夏季：生機盎然的翠綠與薄荷綠 (#4BAF58, #60D394)。
  - 秋季：暖金黃、焦橙與楓紅 (#E09F3E, #D05332, #9E2A2B)。
  - 冬季：銀霜淡藍、柔雪白 (#E2F1F8, #D4EBF2) 與常青松綠 (#335C67)。
- **水域與海洋**：
  - 南部海灘：淺綠松石色透亮海水 (#48CAE4 -> #0077B6)。
  - 溪流與瀑布：清澈山泉藍 (#90E0EF)。
  - 高地湖泊：深邃寶石青藍 (#023E8A)。
- **角色與生物**：
  - 動漫三頭身比例（Chibi Anime Proportion），大眼明亮、表情生動。
  - 鮮明辨識度：飽和而舒適的配飾、釣魚背心、帽子與工具帶。

## 3. 模型比例與幾何細節
- **角色比例**：約 2.5 ~ 3 頭身，頭部圓潤，手腳活動關節流暢，輪廓線條乾淨。
- **樹木與植被**：多邊形飽滿膨脹感（Rounded stylized canopies），樹幹具輕微扭曲的有機木質紋理。
- **岩石與地貌**：簡潔幾何切面（Beveled / low-poly faceted），搭配平滑過渡的斜坡與沙灘。
- **建築物**：手作木質質感、帆布帳篷、帶有弧形邊角的自動販賣機/交易終端。

## 4. 材質、光照與著色器風格
- **材質特徵**：低粗糙度、微漫射高光、微柔焦環境光遮蔽（SSAO 風格烘焙）。
- **光照系統**：
  - 日間：暖日光 DirectionalLight (45-60度角度) 產生柔和邊緣陰影 + 亮麗的天空半球光 (HemisphereLight)。
  - 黃昏：橙紅暮光，長陰影與金色水面漫射反射。
  - 夜間：柔和月光冷青調 + 營火與燈籠的暖橙色點光源與火星粒子。
- **水面著色**：具備動態波紋、半透明頂點位移與岸邊白色浪花泡沫線（Shoreline foam）。

## 5. UI 與介面層級
- **設計風格**：圓角卡片（Border-radius: 16px-24px）、玻璃擬態背景、明快圖標、動態彈出與彈簧縮放微動畫。
- **字體層級**：高可讀性圓體與無襯線字體，層次清晰，資訊重點以金黃與薄荷綠強調。
- **跨平台適應**：桌面支援鍵盤快捷提示；平板（iPad）放大點擊熱區至至少 48px，保留充足安全邊界。
