# 素材清單與技術驗收紀錄 (Asset Inventory)

本檔案記錄遊戲中所使用的全部核心 3D 模型、音訊、紋理與效果，包含技術規格、面數、動畫需求、美術審查與跨平台效能結果。

## 1. 玩家角色 (Player Character)
- **素材識別碼**：`CHR_FISHER_BOY`
- **類別**：玩家 3D 模型與骨架動畫
- **使用場景**：全局主角、角色自訂預覽、探索與釣魚
- **幾何面數**：約 1,850 三角面（高度最佳化）
- **動畫需求**：待機呼吸 (Idle)、行走 (Walk)、奔跑 (Sprint)、揮竿拋線 (Cast)、收竿拉扯 (Reel)、捕獲慶祝 (Cheer)
- **技術驗收結果**：Three.js 階層式關節動畫與骨架正常綁定，縮放 1.0，原點位於雙腳接觸面。
- **美術驗收結果**：符合動漫少年與動森圓潤風格，可自由自訂髮型、髮色、膚色、背心外觀。
- **正式使用狀態**：正式驗收通過

## 2. 自然環境與六大地貌 (Island Terrain & Environment)
- **素材識別碼**：`ENV_ISLAND_6BIOMES`
- **包含組件**：南部沙灘、森林溪流、北部懸崖、中央高地湖、森林秘境、近岸礁岩
- **植被模型**：圓潤松樹 (Tree Pine)、圓潤闊葉樹 (Tree Round)、灌木 (Bushes)、繁花 (Flower Patches)
- **水體系統**：透亮動態頂點波紋水體、即時咬鉤水花漣漪
- **幾何面數**：全島約 12,000 面，採 LOD 與階層視錐剔除
- **四季動態材質**：春（繁花粉綠）、夏（濃密生機）、秋（金楓紅葉）、冬（銀霜積雪）
- **技術驗收結果**：Windows 60fps / iPad 60fps 平滑運行
- **正式使用狀態**：正式驗收通過

## 3. 水生生物資料庫 (Aquatic Creatures)
- **素材識別碼**：`CREATURE_SPEC_COLLECTION`
- **已知物種**：
  1. 三點鮭 (Three-dot Salmon) - 魚類，中型，溪流/湖泊
  2. 蒼蘭鮪 (Azure Tuna) - 魚類，大型，近岸礁岩海域
  3. 紅霞鯛 (Sunset Sea Bream) - 魚類，中型，南部沙灘外海
  4. 黑紋鰻 (Black-striped Eel) - 魚類，長條流線型，森林溪流與秘境
  5. 波光魚 (Glimmer Fish) - 魚類，小型微光，夜間與陰雨特殊魚種
  6. 藍鑽蝦 (Blue Diamond Shrimp) - 蝦類，小型晶瑩甲殼，溪流淺灘
  7. 蒼甲蝦 (Azure Carapace Shrimp) - 蝦類，中型深海，礁岩潮池
  8. 紅楓蟹 (Maple Crab) - 螃蟹，橫行步態，秋季與森林秘境
  9. 紅巨蟹 (Giant Red Crab) - 螃蟹，大型雙鉗，懸崖深海
  10. 白珠貝 (White Pearl Clam) - 貝類，雙殼開合，南部沙灘砂質底
  11. 灰背貝 (Grey-back Clam) - 貝類，厚殼，岩岸潮間帶
- **動畫需求**：水中游動飄動 (Swim wave cycle)、出水掙扎、展示旋轉
- **正式使用狀態**：正式驗收通過
